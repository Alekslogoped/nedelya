# Маша и семь разноцветных дней

Статичная акварельная флип-книга-комикс из 20 страниц с интерактивной игрой «Собери неделю».

- Каждая сюжетная страница — отдельная иллюстрация с репликами внутри картинки.
- Все семь карточек и мест для них находятся вместе на странице 18.
- Можно перетягивать карточки мышью или пальцем, либо нажать на карточку и затем на её место.
- Кнопка «Все картинки» открывает галерею; нажатие на иллюстрацию увеличивает её.
- На компьютере книга раскрывается разворотом, на небольшом экране показывает по одной странице.
- Иллюстрации неподвижны; анимация используется только для перелистывания.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Книга работает без внешних библиотек и шрифтов. Иллюстрации находятся в папке `assets`.
